Эпоха рутинного кодирования уходит. Эти инструменты умножают продуктивность:

| Инструмент | Описание | Ссылка |
|---|---|---|
| **Cursor IDE** | AI-ориентированный редактор с парадигмой Agentic-first. Глубокий контекстный рефакторинг на BSL. | [cursor.com](https://cursor.com) |

## 📖 Фундаментальная литература

### Для начинающих (Junior)

1. **М. Радченко «1С:Программирование для начинающих. Разработка в системе 1С:Предприятие 8.3»**
   — Идеальная первая книга. Написана доступно, с примерами.

2. **М. Радченко, Е. Хрусталева «1С:Предприятие 8.3. Практическое пособие разработчика»**
   — MUST READ для создания фундамента. Охватывает объекты метаданных, BSL и язык запросов.

### Для уверенных разработчиков (Middle / Senior / Expert)

3. **Е. Хрусталева «Разработка сложных отчётов в 1С:Предприятии 8. Система компоновки данных»**
   — Библия по СКД. Обязательна для Middle+.

4. **«Настольная книга 1С:Эксперта по технологическим вопросам»**
   — Для тех, кто хочет понять кластеры, анализ ТЖ, дедлоки, фоновую реструктуризацию и оптимизацию PostgreSQL / MS SQL. Читать после 2–3 лет практики.

> ⚠️ Книги по платформе **8.2** (например, Хрусталева «Реализация прикладных задач в 1С:Предприятие **8.2**») — **устарели**. Современная платформа (8.3.24+, 8.5) строится на управляемых формах, расширениях и клиент-серверной модели, которые в 8.2-книгах не отражены. Не используйте их как основной источник.
