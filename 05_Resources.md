# 📚 Обязательные ресурсы для 1С-разработчика

В мире 1С информация обновляется крайне быстро (новые версии платформы выходят 2-3 раза в год, законодательство меняется ежемесячно). Поэтому 1С-разработчику необходимо опираться на проверенные и актуальные источники.

---

## 📖 Фундаментальная литература (Книги)

### Для начинающих (Junior):
1. **М. Радченко "1С:Программирование для начинающих. Разработка в системе 1С:Предприятие 8.3"** — идеальная первая книга, если вы вообще не умеете программировать.
2. **М. Радченко, Е. Хрусталева "1С:Предприятие 8.3. Практическое пособие разработчика"** — MUST READ для создания фундамента знаний. Примеры из нее встречаются на собеседованиях.
3. **Основы бухучета для программистов (любая актуальная)** — критически важно для понимания логики конфигураций.

### Для уверенных разработчиков (Middle / Senior):
4. **Е. Хрусталева "Разработка сложных отчётов в 1С:Предприятии 8. Система компоновки данных"** — библия разработчика отчетов на СКД. Читать от корки до корки (лучше после 6-9 месяцев практики).
5. **Е. Хрусталева "Реализация прикладных задач в системе 1С:Предприятие 8.2"** — хотя версия старая, фундаментальные принципы оперативного и бухгалтерского учета актуальны.
6. **"Настольная книга 1С:Эксперта по технологическим вопросам"** — обязательна для тех, кто хочет настраивать кластеры, анализировать долгие запросы и оптимизировать производительность (особенно PostgreSQL / MS SQL).

## 🌐 Сообщества, Форумы и Telegram-каналы

Комьюнити 1С — одно из самых мощных русскоязычных IT-сообществ. Без умения гуглить и спрашивать у коллег выжить невозможно.

### 🏆 Главные порталы:
1. **[Infostart.ru](https://infostart.ru)** — крупнейший портал со статьями, готовыми обработками, решениями. **Must-have** (нужна регистрация и накопление "стартмани").
2. **[Миста (forum.mista.ru)](https://forum.mista.ru)** — старейший и самый активный форум 1С-ников. Там можно найти ответы на 90% "тупиковых" вопросов. Будьте готовы к специфическому (жесткому, но полезному) общению.
3. **[ИТС (its.1c.ru)](https://its.1c.ru)** — официальная документация, стандарты разработки 1С (очень важно соблюдать их на проектах).

### 🔥 Telegram-сообщества (где можно задать вопрос):
- **[@esres_1c](https://t.me/esres_1c)** — 🌟 **ТОП-рекомендация!** Очень адекватное сообщество для вопросов (особенно новичкам), быстрые и качественные ответы.
- **[@e1c_community](https://t.me/e1c_community)** — крупнейшее официальное сообщество разработчиков.
- **[Желтый Клуб (yellowclub)](https://t.me/yellowclub)** — сильное комьюнити, обсуждение архитектуры, менеджмента и серьезных технических задач.

## 💻 Open Source проекты и GitHub-репозитории

Современный 1С-разработчик активно использует инструменты экосистемы, написанные на других языках (или на OneScript) для автоматизации своей работы.

1. **[Oscript-library (OneScript)](https://github.com/oscript-library)**
   - Библиотеки скриптов для OneScript (аналог bash/powershell, но с синтаксисом 1С).
   - Инструменты: `gitsync` (выгрузка баз в git), `v8runner` (автоматизация запуска 1С), `packman` (пакетный менеджер).
2. **[Vanessa Automation (BDD)](https://github.com/Pr-Mex/vanessa-automation)**
   - Фреймворк для сценарного (пользовательского) тестирования баз 1С (Behavior Driven Development).
3. **[Yax / xddTestRunner (TDD)](https://github.com/xDrivenDevelopment/xddTestRunner)**
   - Фреймворки для написания Unit-тестов (модульного тестирования) кода 1С.
4. **[BSL Language Server](https://github.com/1c-syntax/bsl-language-server)**
   - Сервер языка 1С (ОСВ), основа для статического анализа кода (SonarQube) и поддержки 1С в VS Code.
