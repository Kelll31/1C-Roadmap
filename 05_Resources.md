# 📚 Обязательные ресурсы для 1С-разработчика в 2026 году

В мире 1С информация обновляется крайне быстро. В 2026 году 1С-разработчику необходимо опираться не только на классическую литературу, но и на передовые AI-инструменты и Open Source проекты.

---

## 🤖 Инструменты Искусственного Интеллекта (AI & LLM)

Эпоха рутинного написания кода уходит. Используйте эти инструменты для автоматизации:

1. **[Cursor IDE](https://cursor.com)**
   - AI-ориентированный редактор кода. Поддерживает парадигму Agentic-first для глубокого контекстного рефакторинга.
2. **Пакет 1c-ai-development-kit**
   - Комплексный набор правил и скиллов для AI-агентов, обученных синтаксису 1С (BSL) и архитектуре метаданных. Интегрируется с Cursor IDE.
3. **MCP-сервер `spremotely-vanessa-app-mcp`**
   - Мост между AI-моделями (Claude, GPT) и фреймворком Vanessa Automation. Позволяет ИИ самостоятельно генерировать .feature файлы (TurboGherkin), писать код шагов и запускать тесты.

---

## 💻 Open Source проекты и DevOps

Современный 1С-разработчик работает в распределенных командах и использует CI/CD:

1. **[Vanessa Automation (BDD)](https://github.com/Pr-Mex/vanessa-automation)**
   - Индустриальный стандарт 2026 года для сценарного тестирования (Behavior Driven Development). Использует язык TurboGherkin. Забудьте про ручное тестирование.
2. **[Oscript-library (OneScript)](https://github.com/oscript-library)**
   - Библиотеки скриптов для автоматизации.
3. **[BSL Language Server](https://github.com/1c-syntax/bsl-language-server)**
   - База для статического анализа кода (SonarQube) и поддержки 1С в различных редакторах.

## 📖 Фундаментальная литература (Книги)

### Для начинающих (Junior):
1. **М. Радченко "1С:Программирование для начинающих. Разработка в системе 1С:Предприятие 8.3"** — идеальная первая книга.
2. **М. Радченко, Е. Хрусталева "1С:Предприятие 8.3. Практическое пособие разработчика"** — MUST READ для создания фундамента знаний.
3. **Основы бухучета для программистов (с учетом налоговой реформы 2026)** — критически важно для понимания логики конфигураций.

### Для уверенных разработчиков (Middle / Senior / Expert):
4. **Е. Хрусталева "Разработка сложных отчётов в 1С:Предприятии 8. Система компоновки данных"** — библия разработчика отчетов на СКД.
5. **"Настольная книга 1С:Эксперта по технологическим вопросам"** — обязательна для тех, кто хочет настраивать кластеры, анализировать долгие запросы, понимать работу фоновой реструктуризации и оптимизировать производительность (особенно PostgreSQL / MS SQL).
