# 📊 Уровни компетенций разработчика 1С (Junior → Expert)

Карьерный трек 1С-разработчика сегодня — это не просто выслуга лет. Это постоянное усложнение архитектуры, глубокое погружение в смежные области (СУБД, DevOps, системный анализ) и умение решать задачи бизнеса на макроуровне. Ниже представлено актуальное описание компетенций на 2025 год.

---

## 🌱 Junior (0–6 месяцев): Освоение базы

**🎯 Основной фокус:** Изучение платформы, понимание бизнес-сущностей, выполнение задач под присмотром наставника.

### Ключевые компетенции:
- **Знание платформы 1С:Предприятие 8.3:** Конфигуратор, структура метаданных (Справочники, Документы, Регистры).
- **Основы языка:** Уверенное написание процедур и функций на встроенном языке (Клиент/Сервер).
- **Базовый язык запросов:** Консоль запросов, простые выборки, виртуальные таблицы, соединения (ЛЕВОЕ/ВНУТРЕННЕЕ).
- **Предметная область:** Базовое понимание бухгалтерского учета (счета, двойная запись, проводки), сущность первичных документов.
- **Инструментарий:** Умение работать с отладчиком (в т.ч. серверная отладка).
- **Сертификация:** Успешная сдача "1С:Профессионал" по платформе.

**💰 Зарплатная вилка:** 50,000 – 90,000 ₽

**📚 Рекомендуемые книги/ресурсы:**
- М. Радченко "1С:Программирование для начинающих"
- Курс "Основы бухучета для программистов"

---

## 🌿 Junior+ (6–12 месяцев): Уверенная самостоятельность

**🎯 Основной фокус:** Самостоятельное решение типовых задач, работа с чужим кодом, начало работы с расширениями.

### Ключевые компетенции:
- **Разработка пользовательского интерфейса:** Понимание управляемых форм, работа с динамическими списками.
- **Объекты конфигурации:** Понимание механизмов проведения документов (оперативное/неоперативное), регистров накопления и сведений.
- **Расширения:** Умение модифицировать типовые конфигурации через расширения (без снятия с поддержки), знание аннотаций (Вместо, После, Перед).
- **Отчетность:** Уверенная работа с табличными документами, макетами печатных форм, базовые знания Системы Компоновки Данных (СКД).
- **БСП (Библиотека стандартных подсистем):** Понимание принципов работы и использование базового API (создание внешних обработок, печатных форм).
- **Инструменты командной разработки:** Базовые навыки работы с Git (через EDT или gitsync/v8unpack) — коммиты, ветки, пулл-реквесты.

**💰 Зарплатная вилка:** 90,000 – 140,000 ₽

**📚 Рекомендуемые книги/ресурсы:**
- Документация 1С:ИТС по Расширениям и Управляемому приложению.
- Е. Хрусталева "Практическое пособие разработчика".

---

## 🍃 Middle (1–2 года): Серьезная разработка и Интеграции

**🎯 Основной фокус:** Самостоятельное проектирование подсистем, сложные интеграции, работа с типовыми конфигурациями.

### Ключевые компетенции:
- **Продвинутая СКД:** Сложные связи наборов данных, вложенные схемы, программное формирование отчетов, расшифровки.
- **Типовые решения:** Глубокое понимание архитектуры 1С:БП (Бухгалтерия), 1С:УТ (Управление торговлей) или 1С:ЗУП (Зарплата).
- **Интеграции и обмен данными:** HTTP/REST API, публикация веб-сервисов (SOAP, OData), форматы обмена JSON/XML/XDTO. Базовые навыки работы с брокерами сообщений (RabbitMQ, Kafka) через ВК.
- **Оптимизация производительности (Базовый уровень):** Понимание индексов СУБД, временных таблиц, оптимизация циклов, избежание запросов в цикле.
- **Инструментарий DevOps:** Уверенная работа в 1С:EDT, автоматизация рутинных задач с помощью OneScript.
- **Сертификация:** Успешная сдача "1С:Специалист" по платформе или по прикладным решениям.

**💰 Зарплатная вилка:** 150,000 – 220,000 ₽

**📚 Рекомендуемые книги/ресурсы:**
- Е. Хрусталева "Разработка сложных отчетов в 1С".
- Учебные курсы по обмену данными и интеграции 1С.

---

## 🌳 Middle+ / Senior- (2–3 года): Архитектура и Производительность

**🎯 Основной фокус:** Оптимизация высоконагруженных систем, архитектурные решения, автоматизация CI/CD.

### Ключевые компетенции:
- **Высокие нагрузки (Highload):** Работа с транзакциями, управляемые блокировки, решение проблем дедлоков (Deadlocks). Анализ технологического журнала 1С.
- **Оптимизация СУБД:** Глубокое понимание PostgreSQL (или MS SQL). Умение читать планы запросов, оптимизация структур таблиц, работа с pg_stat_statements.
- **DevOps в 1С:** Настройка полноценного CI/CD пайплайна (GitLab CI, GitHub Actions, Jenkins), статический анализ кода (SonarQube + BSL Language Server).
- **Автоматизированное тестирование:** Разработка сценарных (BDD) и юнит-тестов с помощью Vanessa Automation, Yax.
- **Инфраструктура:** Развертывание кластера 1С, понимание работы рабочих процессов (rphost), балансировка нагрузки, работа в среде Linux.
- **Менторство:** Проведение код-ревью (Code Review), обучение Junior разработчиков, написание технической документации.

**💰 Зарплатная вилка:** 220,000 – 300,000 ₽

**📚 Рекомендуемые книги/ресурсы:**
- "Настольная книга 1С:Эксперта по технологическим вопросам".
- Документация Vanessa Automation.

---

## 🌲 Senior (4+ года): Техническое лидерство и Корпоративные системы

**🎯 Основной фокус:** Руководство проектами, архитектура enterprise-уровня (1С:ERP), управление техническим долгом.

### Ключевые компетенции:
- **Экспертиза 1С:ERP:** Глубокое знание подсистем (Производство, Финансы, Бюджетирование, МСФО). Внедрение систем класса ERP/Корп.
- **Системная архитектура:** Проектирование ландшафта информационных систем (микросервисный подход, использование 1С:Шины, 1С:Аналитики).
- **1С:Предприятие.Элемент:** Разработка клиент-серверных приложений на новой платформе, проектирование веб-кабинетов.
- **Техническое лидерство (Tech Lead):** Управление распределенными командами разработки, принятие стратегических технических решений, выбор стека технологий.
- **Управление качеством:** Выстраивание процессов тестирования, Continuous Integration / Continuous Delivery масштабов предприятия.
- **Консалтинг:** Взаимодействие с бизнес-заказчиками, перевод бизнес-требований на язык технической архитектуры.

**💰 Зарплатная вилка:** 300,000 – 450,000 ₽

---

## 🏆 Expert / Architect (6+ лет): Стратегия и R&D

**🎯 Основной фокус:** Решение нерешаемых проблем, R&D, влияние на развитие экосистемы 1С.

### Ключевые компетенции:
- **Техническая экспертиза высшего уровня:** Аудит и реинжиниринг крупнейших 1С-инсталляций в стране (тысячи одновременных пользователей, терабайтные базы).
- **Сертификация:** Статус "1С:Эксперт по технологическим вопросам" (высшая ступень квалификации).
- **Создание продуктов:** Разработка собственных тиражных решений на платформе 1С или фреймворков для сообщества (Open Source).
- **Консалтинг C-level:** Формирование IT-стратегий холдингов, обоснование выбора технологий перед топ-менеджментом.
- **Сообщество:** Статус MVP, выступления на Infostart Event, Желтом Клубе, публикация фундаментальных статей.

**💰 Зарплатная вилка:** 450,000 – 1,000,000+ ₽ (и выше, часто проектная/консалтинговая работа)
