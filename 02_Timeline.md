# ⏰ Детальный план освоения по месяцам и неделям

## 🟢 МЕСЯЦ 1: Фундамент и терминология

### Неделя 1-2: Установка и первые шаги
**Цель:** Подготовить рабочее окружение и освоить базовый интерфейс.

**📋 Задачи:**
- Установка платформы 1С:Предприятие 8.3 (учебная версия) под Windows и Linux.
- Установка 1С:EDT (современная IDE).
- **КРИТИЧЕСКИ ВАЖНО:** Установка приложения **1С:Ник** и начало подготовки к сертификации.
- Изучение интерфейса Конфигуратора и базовых принципов работы в EDT.
- Создание первой информационной базы.

**📚 Ресурсы:**
- [Официальный сайт 1С](https://1c.ru) — скачивание платформы.
- [1С:Ник в App Store](https://apps.apple.com/ru/app/1%D1%81-%D0%BD%D0%B8%D0%BA/id1556015943) / [Google Play](https://play.google.com/store/apps/details?id=ru.publishing1c.nik).
- [Документация по установке EDT](https://its.1c.ru/db/edtdoc).

**⚠️ Подводные камни:**
- Антивирус может блокировать файлы 1С — добавьте в исключения.
- Проблемы с локалью базы (особенно в Linux) — всегда используйте русскую локаль (ru_RU.UTF-8).
- Несовместимость версий Java, EDT и платформы.

### Неделя 3-4: Сертификация и основы бухучета
**Цель:** Получить сертификацию 1С:Профессионал и освоить базовую терминологию.

**📋 Задачи:**
- **Сдача сертификации 1С:Профессионал по платформе** (30 вопросов, 30 минут).
- Изучение основ бухгалтерского учета для программистов.
- Понимание понятий: проводка, дебет, кредит, двойная запись, счета учета.
- Создание первых справочников и документов.

**📚 Ресурсы:**
- [Подготовка к 1С:Профессионал](https://1c.ru/prof/prof.htm).
- **1С:Ник** — покупка курса "1С:Профессионал" и ежедневная практика.
- [Основы бухучета для программистов](https://helpme1s.ru/osnovy-buxgalterskogo-uchyota-dlya-programmistov-1s).

## 🟡 МЕСЯЦ 2-3: Конфигурирование и метаданные

### Неделя 5-8: Объекты конфигурации
**Цель:** Освоить работу с базовыми объектами метаданных.

**📋 Задачи:**
- Справочники: иерархические, с табличными частями, подчиненные справочники.
- Документы: проведение, оперативное/неоперативное проведение, обработка проведения.
- Регистры: сведений (периодические, независимые), накопления (остатки, обороты), бухгалтерии, расчета.
- Перечисления, планы видов характеристик, планы счетов, планы видов расчета.
- Создание простых форм объектов.

**📚 Ресурсы:**
- М. Радченко "1С программирование для начинающих" (последнее издание).
- [ITS Руководство разработчика гл. 1-4](https://its.1c.ru/db/v838doc/browse/13/-1/5).

### Неделя 9-12: Встроенный язык и язык запросов
**Цель:** Освоить программирование на встроенном языке 1С и SQL-подобный синтаксис запросов.

**📋 Задачи:**
- Синтаксис языка: переменные, процедуры, функции (клиент-серверное взаимодействие: НаСервере, НаКлиенте).
- Управляющие конструкции: Если, Цикл, Для каждого.
- Работа с коллекциями: массивы, структуры, соответствия, таблицы значений, деревья значений.
- Язык запросов: базовые SELECT, соединения (ЛЕВОЕ, ВНУТРЕННЕЕ, ПОЛНОЕ), группировки, ВТОМЧИСЛЕ, ВЫРАЗИТЬ, ЕСТЬNULL.
- Виртуальные таблицы регистров. Консоль запросов.
- Обработка событий форм (ПриСозданииНаСервере, ПриОткрытии, ОбработкаОповещения).

**⚠️ Подводные камни:**
- Неопределенные переменные — используйте строгую типизацию.
- Неправильная работа с типами данных и ссылками.
- Непонимание контекста выполнения (Клиент/Сервер) и вызов серверных методов в цикле на клиенте.
- Запросы в цикле (грубейшая ошибка производительности).

## 🟠 МЕСЯЦ 4-6: Углубление в предметную область и DevOps

### Неделя 13-20: Предметная область и типовые конфигурации
**Цель:** Глубоко изучить бизнес-логику и готовые решения.

**📋 Задачи:**
- **Углубленное изучение бухгалтерского учета:** План счетов, регистры бухгалтерии, ОС и НМА, НДС, налоговый учет.
- Работа с архитектурой и кодом типовых конфигураций: "1С:Бухгалтерия предприятия", "1С:Управление торговлей".
- **Маркировка товаров (Честный ЗНАК):** жизненный цикл маркированного товара, интеграция с ИС МП.

**📚 Ресурсы:**
- Курс "Бухучет для программистов".
- Маркировка товаров в 1С (официальная документация ИТС).
- Демонстрационные базы типовых конфигураций (БП, УТ, ERP).

### Неделя 21-24: Расширения, Версионирование (Git) и EDT
**Цель:** Освоить современные практики и инструменты командной разработки.

**📋 Задачи:**
- Расширения конфигурации (безопасный режим, заимствование, переопределение методов: Вместо, После, Перед).
- Основы работы с Git для 1С (коммиты, ветвления, слияния, разрешение конфликтов).
- Переход в 1С:EDT: создание проекта, импорт из базы, экспорт, плагины EDT.
- Использование gitsync / v8unpack для работы с выгрузками в формате XML в связке с Git.

**📚 Ресурсы:**
- Видеокурсы по Git в 1С:EDT (YouTube: Желтый чайник 1С, Илья Леонтьев).
- [Расширения конфигураций на ИТС](https://its.1c.ru/db/v838doc#bookmark1521).

## 🔵 МЕСЯЦ 7-9: Отчеты и Интеграции

### Неделя 25-32: Печатные формы и Система Компоновки Данных (СКД)
**Цель:** Освоить мощнейший инструмент создания отчетов.

**📋 Задачи:**
- Создание внешних печатных форм с подключением к БСП (Библиотека стандартных подсистем).
- Макеты, форматирование, табличные документы.
- **СКД (базовый уровень):** Источники данных (запросы), наборы данных, связи.
- Поля, параметры, отборы.
- Группировки, итоги, ресурсы. Условное оформление и пользовательские настройки.
- Программное формирование отчета на СКД.

**📚 Ресурсы:**
- Е. Хрусталева "Разработка сложных отчётов" (главы 1-3).
- Видеоуроки по СКД (YouTube).

### Неделя 33-36: Обмен данными и Интеграции
**Цель:** Научиться связывать 1С с внешним миром.

**📋 Задачи:**
- Форматы данных: XML, JSON, Base64.
- Чтение/Запись файлов.
- HTTP-запросы (GET, POST, PUT, DELETE), REST API.
- Создание собственных HTTP-сервисов в 1С.
- Использование SOAP веб-сервисов, XDTO-пакеты.
- **Современный стек (введение):** Брокеры сообщений (RabbitMQ / Apache Kafka) через внешние компоненты.

**⚠️ Подводные камни:**
- Проблемы с кодировками (UTF-8/Windows-1251).
- Неверный `Content-Type` или отсутствие заголовков авторизации.
- Блокировки потока при длительных запросах (нужны фоновые задания).

## 🟣 МЕСЯЦ 10-12: Продвинутые технологии и Подготовка к Специалисту

### Неделя 37-44: Архитектура, Оптимизация и CI/CD
**Цель:** Улучшить качество кода и познакомиться с инфраструктурными задачами.

**📋 Задачи:**
- **Оптимизация производительности:** индексы СУБД, дедлоки (взаимоблокировки), управляемые блокировки.
- Анализ планов запросов в PostgreSQL и MS SQL.
- Знакомство с Библиотекой Стандартных Подсистем (БСП): использование готовых API.
- Автоматизация с OneScript: написание скриптов для рутинных задач (обновление баз, выгрузки).
- Введение в CI/CD: базовое понимание процессов автоматической сборки и проверки кода. Использование BSL Language Server (SonarQube) для анализа качества.

**📚 Ресурсы:**
- [OneScript.ru](https://oscript.io/) и [GitHub oscript-library](https://github.com/oscript-library).
- Статьи по оптимизации на Инфостарт.

### Неделя 45-48: Подготовка к 1С:Специалист по платформе
**Цель:** Подтвердить навыки на высшем уровне.

**📋 Задачи:**
- Решение практических задач из экзаменационных билетов.
- Настройка сложного проведения (партийный учет, FIFO/LIFO, себестоимость).
- Сложные запросы (Временные таблицы, Пакетные запросы).
- Сложные периодические расчеты (начисление зарплаты, вытесняющие виды расчета).
- Тренировка скорости написания кода в Конфигураторе без подсказок.

**📚 Ресурсы:**
- [Сборник задач для подготовки к экзамену 1С:Специалист](https://v8.1c.ru/metod/books/120617.htm).
- Практические курсы Учебного Центра №1.
- Видео разборы билетов на YouTube.
