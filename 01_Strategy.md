# 🎯 Стратегия освоения 1С в 2026 году

[← README](README.md) | [Timeline →](02_Timeline.md)

---

Современная разработка на 1С — это уже давно не просто написание модулей в Конфигураторе. В реалиях 2026 года платформа «1С:Предприятие» окончательно закрепилась в статусе высоконагруженной, распределённой ERP-системы мирового класса. Это полноценная экосистема, требующая знаний классических подходов, DevOps-практик, архитектурных паттернов, интеграционных технологий и инструментов на базе искусственного интеллекта.

---

## Основные принципы успеха

- **Триада знаний:** Техника (1С) + Предметная область (бухучёт, производство, торговля) + Бизнес-процессы и Soft Skills.
- **Практика с первого дня** — создавайте реальные мини-проекты. Теория без практики в 1С быстро забывается.
- **Предметная область = фундамент** — без понимания основ бухгалтерского и управленческого учёта вы не поймёте 80% реальных задач от заказчиков. Особое внимание — адаптации систем к изменениям законодательства (НДС 22%, маркировка, МЧД).
- **Эволюционный подход** — от простых конфигураций к сложным высоконагруженным системам. Не пытайтесь охватить всё сразу.
- **Современный стек** — выход за рамки Конфигуратора: 1С:EDT, Git, PostgreSQL, Linux-инфраструктура, AI-инструменты (Cursor IDE, LLM).
- **Строгая архитектурная гигиена** — отказ от ручного вмешательства в типовые модули. Любые доработки — строго через Расширения (Extensions) и механизмы БСП.
- **Сертификация — после изучения материала** — сдача «1С:Профессионал» имеет смысл после освоения синтаксиса BSL, основ метаданных и языка запросов (≈ 2–3 месяц обучения, не первый).

## Ключевые фокусы на 2026 год

### 1. Искусственный интеллект (AI) в разработке 1С

Эпоха рутинного написания шаблонного кода уходит. AI — инструмент, который *умножает* продуктивность, но не заменяет понимание бизнес-логики и архитектуры.

- Интеграция LLM через протокол **Model Context Protocol (MCP)**.
- AI-ориентированные IDE: **Cursor IDE** + пакет **1c-ai-development-kit** (правила и агенты, обученные BSL и архитектуре 1С).
- **MCP-сервер `spremotely-vanessa-app-mcp`** — мост между AI-моделями и фреймворком Vanessa Automation для автоматической генерации тестов.
- **1С:Напарник** — встроенный AI-ассистент для конечных пользователей типовых конфигураций.

### 2. Смена архитектурной парадигмы: 1С:Предприятие 8.5 vs 1С:Элемент

Это не новая версия — это две дополняющие друг друга платформы для разных задач.

| Критерий | 1С:Предприятие 8.5 (Back-office) | 1С:Элемент (Front-office / B2C) |
|---|---|---|
| Архитектура | Монолитная, транзакционная | Микросервисная, асинхронная |
| UI-стек | Управляемые формы (BSL) | HTML / CSS / JavaScript |
| Язык логики | BSL | Новый язык 1С:Элемент (строгая типизация) |
| Платформа | On-premise / Linux / Windows | Cloud-native, контейнеры |
| Сценарии | ERP, бухучёт, ЗУП, производство | Личные кабинеты, маркетплейсы, B2C-порталы |

Для Junior достаточно понимать, **что такое разграничение существует**. Глубокое изучение 1С:Элемент — задача Middle+ / Senior.

### 3. Информационная безопасность (Платформа 8.5)

- Переход на криптостойкие алгоритмы хеширования паролей **PBKDF2-HMAC-SHA256** (замена устаревшему SHA-1).
- Беспарольный вход по **QR-коду** (смартфон как аппаратный токен).
- Контроль сеансов: **Idle Timeout** (автоматическое завершение брошенных сессий).
- Интеграция с **ЕСИА v3.34** и проверка паролей по базам утечек.

### 4. DevOps, CI/CD и BDD-тестирование

- Переход из Конфигуратора в **1C:EDT** для командной разработки и контроля версий.
- **Git** (ветвление, Pull Requests, Code Review) — стандарт индустрии.
- **CI/CD** (GitLab CI / GitHub Actions): автоматическая сборка, статический анализ (SonarQube + BSL Language Server), запуск тестов.
- **BDD / Vanessa Automation + TurboGherkin**: поведенческое тестирование вместо хрупких UI-тестов. Сценарий = живая документация.

### 5. Linux, PostgreSQL и импортозамещение

- Развёртывание сервера 1С на **Astra Linux, РЕД ОС, Ubuntu**.
- PostgreSQL как основная СУБД: понимание индексов, планов запросов, настройки `postgresql.conf`, `pg_stat_statements`.
- Важно уже с уровня **Middle**: Linux — **case-sensitive** (в отличие от Windows), что ломает интеграции и файловые выгрузки при миграции.

### 6. Soft Skills и работа с бизнесом

Часто игнорируемый, но критически важный блок:
- Чтение и составление технических заданий (ТЗ).
- Декомпозиция задач и точные оценки времени (estimation).
- Коммуникация с аналитиками, бухгалтерами, заказчиками.
- Понимание Agile/Scrum-процессов в команде внедрения.

## Специализации: четыре карьерных трека

Эпоха «универсального программиста-внедренца» в одиночку прошла. Определитесь с вектором развития:

| Трек | Фокус | Сертификат |
|---|---|---|
| **Разработка** (Junior → Senior) | BSL, расширения, интеграции, BDD, AI | 1С:Профессионал → 1С:Специалист |
| **Архитектура** (Senior → Architect) | Гибридные ландшафты, CI/CD, EDT, ERP+Элемент | 1С:Специалист + опыт |
| **HighLoad / DevOps** (Эксперт) | PostgreSQL, Linux, кластер 1С, дедлоки, TJ | 1С:Эксперт по ТВ |
| **Бизнес-аналитика** (Консультант) | ERP/ЗУП/УХ, СКД, 1С:СППР, TurboGherkin | 1С:Специалист-Консультант |

## Целевые результаты через 12 месяцев

По завершении плана обучения вы будете уметь:

- ✅ Уверенно работать с платформой 8.3/8.5 (Конфигуратор и 1С:EDT).
- ✅ Понимать основы бухучёта, налоговой реформы 2026 и маркировки товаров.
- ✅ Создавать конфигурации с нуля, использовать Расширения и БСП.
- ✅ Строить сложные отчёты на СКД; работать с языком запросов 1С.
- ✅ Разрабатывать HTTP-сервисы (REST) и интегрировать 1С с внешними системами.
- ✅ Уверенно работать с Git, настраивать базовый CI/CD и писать BDD-сценарии.
- ✅ Применять AI-инструменты (Cursor IDE) для ускорения разработки.
- ✅ Понимать принципы RLS, управляемых блокировок и безопасных обновлений через Расширения.
- ✅ Быть готовым к сдаче экзамена «1С:Специалист по платформе».
